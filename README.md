# Directory Overview

- `_data/` — YAML files containing site data, author information, navigation, comments, and UI text.
- `_drafts/` — Unpublished draft posts and pages.
- `_includes/` — Reusable Jekyll template components used across pages.
- `_layouts/` — Page layouts for posts, talks, archives, and general site content.
- `_pages/` — Main site pages, including the academic profile and archive pages.
- `_sass/` — Sass partials and third-party styles for the site's theme.
- `_talks/` — Talk and presentation content.
- `.github/` — GitHub Actions workflows for automated deployment.
- `assets/` — Stylesheets, JavaScript, fonts, and other client-side resources.
- `google_scholar_crawler/` — Python scripts and dependencies for collecting Google Scholar information.
- `images/` — Profile photos, logos, favicons, and other image assets.
- `markdown_generator/` — Python and Jupyter notebook tools for generating academic publications and talk pages from TSV data.
- `talkmap/` — Leaflet-based interactive map and supporting data for talk locations.
